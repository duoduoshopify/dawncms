# 设计指南：让主题耐看

一套好主题不是"换几个颜色"，而是一组互相配合的决策。这篇讲设计时的取舍。

## 先选路线：换肤还是换骨

| 需求 | 做法 |
|---|---|
| 只改配色 / 字体 | `vars.json` + `extends`，两个文件搞定 |
| 微调样式（圆角、阴影、悬停） | 加 `assets/css/main.css`（或根目录 `style.css`），类名覆盖 |
| 改布局结构（侧栏、网格、导航） | 自带 `templates/`，参考 shimo 或 baiye |
| 覆盖平台基线（正文排版/文档样式） | 放 `assets/core/` 同名文件（如 `doc.css`） |

内置的「宣纸」（shimo）和「白页」（baiye）就是两种路线的完整范例：同一份数据上下文，宣纸走居中杂志式，白页走左侧目录 + 右侧网格。

## 对比度是底线

- `ink` 与 `paper` 对比度 **≥ 7:1**——正文长时间阅读不累
- `accent` 与 `paper` 对比度 **≥ 4.5:1**——链接和小字标签可辨
- 推荐工具：WebAIM Contrast Checker

文字六级（ink → ghost）的层次感靠灰度阶梯维持，相邻两级明度差建议 15% 左右。

## 浅色主题的技巧

- `hairline` 应接近 `paper` 但肉眼可辨——发丝边框的意义是"几乎看不见的结构"
- `wash` 介于 `paper` 和 `hairline` 之间，用于引用块衬底
- 强调色可以略深，白底上饱和色本来就显亮

## 暗色主题的技巧

- `paper` 不要纯黑：带蓝调的黑更耐看
- 行内代码 `code_bg` 要比 `paper` 略亮，才能从背景中浮出来
- `accent` 适当提高亮度（暗底上颜色显暗）
- 文字纯白会刺眼，`ink` 用 `#e8e4da` 这类米白

参考内置的 `noir`（夜航）主题，它就是标准的暗色处理。

## 字体决策

| 风格 | serif | doc_font |
|---|---|---|
| 中式 / 文人 / 杂志 | 衬线栈 | 衬线栈 |
| 科技 / 极简 / 工具 | 无衬线栈 | 无衬线栈 |
| 折中 | 衬线栈 | 无衬线栈 |

中文衬线正文很有书卷气，但字号小于 15px 时会糊，文章页正文默认约 17px 是有意为之。

## style.css / assets/css 书写建议

- 变量类直接改 `vars.json`，CSS 文件留给布局和行为（hover、阴影、transform）
- 模板里大量用了 Tailwind 任意值 `bg-[var(--paper)]`，所以改 token 全局生效
- 常用挂载点类名：`.paper-card`（卡片）、`.cat-tab`（分类胶囊）、`.doc-content`（正文容器）、`.toc-link`（目录项）、`.doc-progress`（阅读进度条）、`.eyebrow`（眉题）
- CSS/JS 沿继承链拼接（父在前、子在后），同优先级下你的规则天然压过父主题——不需要 `!important`，需要提权时用 `body` 前缀

## 检验清单

- [ ] 首页：标题、摘要、日期、分类入口层级清晰
- [ ] 文章页：H2 边条、引用块、行内代码、代码块都可辨
- [ ] 按钮：深色按钮上的文字可读（`paper` 作文字色）
- [ ] 选中文字（::selection）颜色协调
- [ ] 会员徽章、标签 chips 在卡片上不突兀
- [ ] TOC 高亮和阅读进度条颜色跟 accent 一致
